Class OutlookGridAlphabeticGroup

This group simple example of an implementation which groups the items into Alphabetic categories based only on the first letter of each item

For this we need to override the Value property (used for comparison) and the CompareTo function. Also the Clone method must be overriden, so this Group object can create clones of itself. Cloning of the group is used by the OutlookGrid
