Enum FilterItemResult

Provides the return values for the GetAvailableUpdates call on the IAppCastHandler. When an appcast is downloaded, the IAppCastHandler will work out which AppCastItem instances match criteria for an update.

Namespace: System.Dynamic.ExpandoObject
Assembly: Krypton.Toolkit.Suite.Extended.Software.Updater.Core.dll
Syntax
public enum FilterItemResult

NotThisPlatform

The AppCastItem is for a different operating system than this one, and must be ignored.

SignatureIsMissing

A signature is required to validate the item - but it's missing from the AppCastItem

SomeOtherProblem

Some other issue is going on with this AppCastItem that causes us not to want to use it. Use this FilterItemResult if it doens't fit into one of the other categories.

Valid

Indicates that the AppCastItem is a validate candidate for installation.

VersionIsOlderThanCurrent

The version indicated by the AppCastItem is less than or equal to the currently installed/running version.
