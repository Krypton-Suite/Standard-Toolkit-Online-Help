Constructors

Histogram(double, double, int, bool, bool)

Create a histogram which will count values supplied by Add(double) and AddRange(IEnumerable<double>)

Declaration
public Histogram(double min, double max, int binCount, bool addOutliersToEdgeBins = false, bool addFinalBin = true)
Parameters
double min

minimum value to be counted
double max

maximum value to be counted
int binCount

number of bins between min and max
bool addOutliersToEdgeBins

if false, outliers will not be counted
bool addFinalBin

if true, one more bin will be added so values equal to max can be counted too
Remarks

If min and max are the same value, the min and max properties will be min - 0.5 and max + 0.5, respectively. This is to handle an edge case where all values of an array are exactly the same, producing an identical min and max.
