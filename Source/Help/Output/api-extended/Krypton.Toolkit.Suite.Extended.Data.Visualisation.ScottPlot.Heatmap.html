Axes

This object performs coordinate/pixel translation at render time based on the latest data area. It stores the axes to use for this plottable and also the data area (in pixels) updated just before each render. If this object is null it will be constructed using the default X and Y axes at render time.

FlipVertically

This variable controls whether row 0 of the 2D source array is the top or bottom of the heatmap. When set to false (default), row 0 is the top of the heatmap. When set to true, row 0 of the source data will be displayed at the bottom.
