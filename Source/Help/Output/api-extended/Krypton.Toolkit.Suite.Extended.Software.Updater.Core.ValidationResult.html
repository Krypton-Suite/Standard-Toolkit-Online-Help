Enum ValidationResult

Return value of the signature verification check functions.

Namespace: System.Dynamic.ExpandoObject
Assembly: Krypton.Toolkit.Suite.Extended.Software.Updater.Core.dll
Syntax
public enum ValidationResult

Invalid

Depending on the SecurityMode used, either the public key or the signature doesn't exist -- or they exist but are not valid. In this case the update file will be rejected.

Unchecked

There wasn't any public key or signature available, and this is OK based on the SecurityMode used.

Valid

The public key and signature both exist and they are valid (the update file is safe to use).
