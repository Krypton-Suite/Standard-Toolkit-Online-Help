Class KryptonProgressBarExtended

Represents a Windows progress bar control which displays its System.Windows.Forms.ProgressBar.Value as text on a faded background. Based off of: https://www.codeproject.com/Articles/1082902/How-to-Paint-on-Top-of-a-ProgressBar-using-Csharp

Remarks

KryptonProgressBarExtended is a specialized type of ProgressBar, which it extends to fade its background colors and to display its Text.

You can manipulate the background fading intensity by changing the value of property Fade which accepts values between 0 and 255. Lower values make the background darker; higher values make the background lighter.

The current System.Windows.Forms.ProgressBar.Text is displayed using the values of properties Font and ForeColor.

Gets or sets the opacity of the white overlay brush which fades the background colors of the KryptonProgressBarExtended.

Property Value
int

An int representing the alpha value of the overlay color. The default is 150.
Remarks

You can use this property to manipulate the density of the background coloring of this control, to allow for better readability of any text within the KryptonProgressBarExtended. You can use the Font and ForeColor properties to further optimize the display of text.

Acceptable values for this property are between 0 and 255 inclusive. The default is 150; lower values make the background darker; higher values make the background lighter.

Exceptions
ArgumentOutOfRangeException

The value assigned to the property is less than 0 or greater than 255.

Remarks

You can use the Font property to change the Font to use when drawing text. To change the text Color, use the KryptonProgressBarExtendedVersion2.ForeColor property.

The Font property is an ambient property. An ambient property is a control property that, if not set, is retrieved from the parent control.

Because the Font class is immutable (meaning that you cannot adjust any of its properties), you can only assign the Font property a new Font. However, you can base the new font on the existing font.
