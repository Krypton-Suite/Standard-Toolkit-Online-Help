Enum KryptonUpdateCheckStatus

Outcome of CheckAsync(CancellationToken) or CheckNowAsync(CancellationToken).

Namespace: Krypton.Toolkit.Utilities
Assembly: Krypton.Toolkit.Utilities.dll
Syntax
public enum KryptonUpdateCheckStatus

Applied

The package was verified and the installer or helper was started.

Cancelled

The user or a cancelling event handler stopped the check, download, or apply.

Failed

The feed, download, verification, or apply failed. See Error.

Idle

The call did not contact the feed because the mode is manual.

IgnoredInterval

A scheduled check was skipped because the last check is still inside CheckInterval.

Postponed

The user asked to be reminded later, or a scheduled check is still inside that window.

Skipped

This version was skipped. A newer version is still reported.

UpToDate

The feed has no version newer than the current one.
