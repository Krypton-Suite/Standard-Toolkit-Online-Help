Class KryptonComputeFileCheckSum

Provides static methods for displaying dialogs that compute or verify file checksums using supported hash algorithms.

Remarks

This class is intended for use in Windows Forms applications to facilitate file checksum operations through modal dialogs. All methods are static and display dialogs for selecting files, computing hashes, or verifying file integrity. The dialogs can be owned by a parent window or shown centered on screen if no owner is specified.
