Remarks

Use this class to configure the OAuth2 authorization code flow with PKCE. PKCE is recommended for public clients (e.g., desktop/mobile apps) that cannot securely store a client secret.

Required properties: Authority, ClientId, and RedirectUri. The authority is typically the base URL of your OAuth2/OpenID Connect provider (e.g., "https://login.microsoftonline.com/tenant-id/v2.0").
