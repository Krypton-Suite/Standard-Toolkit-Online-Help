Version version

Package version. Compared with Version ordering.
KryptonUpdateSeverity severity

How the prompt and automatic mode treat the package.
KryptonUpdatePackageKind packageKind

Installer or zip archive.
string packageUrl

HTTPS address or a local file path.
string sha256

64 hex characters. Compared in constant time after download.
string certificateThumbprint

When set, the file must be Authenticode-signed with this thumbprint.
string releaseNotes

Text shown in the prompt. May be null.
string installerArguments

Arguments passed to an installer. Ignored for a zip.
DateTime? releasedUtc

Published time from the feed, when present.
int? maximumPostponeDays

Latest remind-later date, in days from today. Null uses DefaultMaximumPostponeDays.
bool? allowPostpone

When null, a critical package cannot be postponed and every other severity can. When set, that choice wins.
bool? allowSkip

When null, a critical package cannot be skipped and every other severity can. When set, that choice wins.
bool? allowResume

When null, a partial download can be resumed. When false, Resume is hidden.
bool? allowRetry

When null, a failed download can be started again. When false, Restart is hidden.
KryptonUpdateBanner banner

Optional prompt and notes banner. Null when the manifest omits it.
KryptonUpdatePulse pulse

Optional form chrome glow. Null when the manifest omits it.
