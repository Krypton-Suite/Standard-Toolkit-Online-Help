Enum KryptonLogLevel

Severity of a KryptonLogEvent. Higher values are more severe.

Namespace: System.Dynamic.ExpandoObject
Assembly: Krypton.Toolkit.Utilities.dll
Syntax
public enum KryptonLogLevel

Debug

Debug information useful while developing.

Error

Failures that affect a request or operation.

Fatal

Failures that may require process shutdown or immediate attention.

Information

Normal operational messages.

Trace

Verbose diagnostic detail (disabled in typical production configuration).

Warning

Unexpected but recoverable conditions.
