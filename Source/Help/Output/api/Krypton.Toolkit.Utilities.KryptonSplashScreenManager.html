public sealed class KryptonSplashScreenManager : IDisposable
Remarks

Use Show(KryptonSplashScreenManagerData) plus SetStatus(string) / SetProgress(int, int?), then Close() before Application.Run of the main form. Run(KryptonSplashScreenManagerData, IList<KryptonSplashStep>) executes a sequence of caller-thread steps, updates progress from the step count, and reports exceptions. Distinct from the modal KryptonSplashScreen in Krypton.Toolkit.
