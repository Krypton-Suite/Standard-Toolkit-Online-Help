Remarks

Call Open(Color) when a colour drop-down is shown, Track(Color) while a swatch is highlighted, Commit(Color) when the user chooses a colour, and Cancel() when the drop-down closes without a choice.

Methods do nothing while Enabled is false. Track(Color) treats Empty as leaving the swatches, because that is what TrackingColor reports. No Color is committed with Commit(Color) and is not a hover preview. A Cancel() after Commit(Color) is ignored.
