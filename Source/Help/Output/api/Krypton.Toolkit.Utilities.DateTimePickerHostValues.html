Class DateTimePickerHostValues

Expandable configuration for the KryptonDateTimePickerToolStripItem tool strip host. Mirrors the settable value/behavior settings of the hosted KryptonDateTimePicker (DateTimePickerControl). Pure infrastructure members (ButtonSpecs, ToolTipManager, Images, and the read-only state flags) remain directly on the host.
