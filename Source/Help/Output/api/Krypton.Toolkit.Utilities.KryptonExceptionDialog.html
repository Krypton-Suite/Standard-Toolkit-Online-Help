Show(Exception, bool?, bool?)

Displays a dialog showing details of the specified exception, with optional controls for copying the error information and searching for solutions.

Declaration
public static void Show(Exception exception, bool? showCopyButton, bool? showSearchBox)
Parameters
Exception exception

The exception to display in the dialog. Cannot be null.
bool? showCopyButton

Indicates whether to show a button that allows users to copy the exception details. If true, the copy button is displayed; if false, it is hidden; if null, the default behavior is used.
bool? showSearchBox

Indicates whether to show a search box for users to look up information related to the exception. If true, the search box is displayed; if false, it is hidden; if null, the default behavior is used.

Show(Exception, Color?, bool?, bool?, Action<Exception>?, SecureString?, string?)

Displays a dialog that presents details about the specified exception, with optional UI features and GitHub bug reporting integration.

Declaration
public static void Show(Exception exception, Color? highlightColor, bool? showCopyButton, bool? showSearchBox, Action<Exception>? bugReportCallback, SecureString? githubSecretKey, string? githubConfigPath = null)
Parameters
Exception exception

The exception to display in the dialog. Cannot be null.
Color? highlightColor

An optional color used to highlight key information in the dialog. If null, the default highlight color is used.
bool? showCopyButton

An optional value indicating whether to show a button that allows users to copy exception details. If null, the default behavior is applied.
bool? showSearchBox

An optional value indicating whether to show a search box for filtering exception details. If null, the default behavior is applied.
Action<Exception> bugReportCallback

An optional callback invoked when the user clicks "Report Bug". Ignored if githubSecretKey is provided.
SecureString githubSecretKey

Optional secret key for GitHub bug reporting. When provided, "Report Bug" opens the GitHub issue dialog with exception details pre-filled.
string githubConfigPath

Optional path to the encrypted config file. If null, the default path is used.
Remarks

When githubSecretKey is provided, a "Report Bug" button is shown. Clicking it opens the GitHub issue report dialog with the exception details pre-filled in the Additional Information field. The config is loaded from an encrypted file; see BugReportGitHubConfigEncryption for setup.
