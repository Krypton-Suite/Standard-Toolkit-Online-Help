Class WindowsMuiStrings

Public access to the verified Windows MUI string catalog and System32 resource loading. Prefer Strings.CommonStrings / UseWindowsLanguagePackStrings for product UI. Raw module/resource IDs are undocumented and may change across Windows releases.
