Class KryptonVerifyFileCheckSum

Provides static methods for displaying dialogs that verify the checksum of a file, allowing users to compare file hashes and confirm file integrity.

Remarks

Use the methods in this class to present a modal dialog for verifying file checksums. The dialogs can be associated with a window owner and optionally pre-filled with a file path and expected hash value. This class is intended for use in scenarios where file integrity needs to be confirmed by the user, such as after downloading or transferring files. All methods are static and thread-safe.
