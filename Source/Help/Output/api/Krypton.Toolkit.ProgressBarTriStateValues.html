AutoCalculateThresholdValues

Gets or sets whether to automatically calculate threshold values based on Minimum and Maximum. When enabled, thresholds are calculated as: LowThreshold = Minimum + (Maximum - Minimum) / 3, HighThreshold = Minimum + (Maximum - Minimum) * 2 / 3.
