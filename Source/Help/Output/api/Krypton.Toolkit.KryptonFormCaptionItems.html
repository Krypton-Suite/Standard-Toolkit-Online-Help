Syntax
[ToolboxBitmap(typeof(KryptonForm))]
public class KryptonFormCaptionItems : Component, IComponent, IDisposable, ISupportInitialize
Remarks

Drop this component on a KryptonCaptionForm, set OwnerForm, and add KryptonFormCaptionItem entries to Items. Each item keeps its own FormCaptionTextBoxEdge. At runtime the component calls AddCaptionControl(Control, FormCaptionTextBoxEdge).

Use this when several caption controls are needed. For a single text box, CaptionTextBox is enough and does not require this component.
