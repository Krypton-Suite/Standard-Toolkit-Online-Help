Interface IKryptonColorLivePreview

Opt-in hover preview that does not change the committed colour until the user selects one.

Remarks

Colour controls raise ColorPreview. Hosts apply Color while the action is Preview and restore CommittedColor on Revert or Cancel. Future colour controls drive the same sequence through KryptonColorLivePreviewSession.
