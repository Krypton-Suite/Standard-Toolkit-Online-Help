CustomFadeSpeed

Gets or sets the custom fade-speed units used when FadeSpeed is Custom.

Declaration
public float CustomFadeSpeed { get; set; }
Property Value
float

Remarks

Same units as the built-in fade-speed presets. Values of 1 (slowest) through 100 (fastest) are typical. Values of 0 or less fall back to Normal.

FadeIn

Gets or sets whether a fade-in runs when the form is first shown.

Declaration
public bool FadeIn { get; set; }
Property Value
bool

Remarks

Used only when FadingEnabled is true. Default is true.

FadeOut

Gets or sets whether a fade-out runs when the form is closing.

Declaration
public bool FadeOut { get; set; }
Property Value
bool

Remarks

Used only when FadingEnabled is true. Default is true. Shutdown, task-manager, and application-exit close reasons skip the fade so the process can exit promptly.

FadeSpeed

Gets or sets the fade speed preset.

Declaration
public FadeSpeedChoice FadeSpeed { get; set; }
Property Value
FadeSpeedChoice

Remarks

Presets map to built-in fade-speed units (opacity step scaled by 1000 on a 10 ms timer). Use Custom with CustomFadeSpeed to supply your own units (typically 1–100).

FadingEnabled

Gets or sets whether the form automatically fades in when shown and out when closed.

Declaration
public bool FadingEnabled { get; set; }
Property Value
bool

Remarks

Default is false. When enabled, FadeIn and FadeOut control each direction. Manual FadeIn() / FadeOut() still work when this is false.
