Remarks

Supports authorization code exchange and token refresh. Use AuthorizeWithBrowserAsync(IWin32Window?, string, CancellationToken) for the full flow (opens a Krypton-styled sign-in window with WebView2), or call BuildAuthorizationUrl(string, string?), obtain the code via your own browser, then ExchangeCodeAsync(string?, string, CancellationToken).

Example (Azure AD / Microsoft Entra): 

var options = new OAuth2PkceOptions
{
    Authority = "https://login.microsoftonline.com/{tenant-id}/v2.0",
    ClientId = "your-client-id",
    RedirectUri = "myapp://callback",
    Scopes = "openid profile User.Read"
};
var client = new OAuth2PkceClient(options);
var tokens = await client.AuthorizeWithBrowserAsync(this, "Sign in to My App");
// Use tokens.AccessToken for API calls; tokens.RefreshToken to refresh when expired.
