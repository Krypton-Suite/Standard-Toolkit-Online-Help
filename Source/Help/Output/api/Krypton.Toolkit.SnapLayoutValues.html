Syntax
[TypeConverter(typeof(ExpandableObjectConverter))]
public class SnapLayoutValues : Storage, IGlobalId
Remarks

Edit this object on a KryptonManager in the property grid, or use SnapLayoutValues from code. The menu reads the values when it opens.

CustomLayouts

Gets the custom snap-layout cards appended after the builtin cards.

Declaration
public KryptonSnapLayoutCardCollection CustomLayouts { get; }
Property Value
KryptonSnapLayoutCardCollection

Remarks

Empty by default, which leaves the builtin menu unchanged. Add a card, then add zones whose edges are fractions of the work area from 0 to 1. The menu copies this list when it opens.

bool

Remarks

The default is true. Set this to false to show only CustomLayouts. An empty custom list and false shows no menu.

KryptonSnapLayoutMode

System (the default) keeps the Windows 11 snap menu. Toolkit draws the palette menu and snaps that form. None is maximize and restore only. Inherit is stored as System.
