Parameters
ButtonSpec spec

Button spec instance.
Returns
ViewDockStyle

Dock style to assign before RTL mirroring.
Remarks

Maps palette Near/Far edge to Left/Right dock. Form chrome relies on GetButtonSpecEdge(PaletteButtonSpecStyle) to move standard Far-edge buttons to the physical left in RTL (Far→Near remap) rather than depending on CalculateDock(ViewDockStyle, Control?) alone, which does not consistently mirror caption button specs (issue #3786).
