AutoDiscoverTranslations

Gets or sets whether KryptonManager automatically probes the application's base directory for culture-specific and default translation files at type-initialisation time and loads the best match if found. Defaults to true.

Declaration
public static bool AutoDiscoverTranslations { get; set; }
Property Value
bool

Remarks

Set to false before the first use of any Krypton type to suppress auto-discovery, for example in unit-test hosts or apps that manage translations entirely in code. Auto-discovery is silent — any I/O or parse errors are swallowed and traced to Debug. Probe order: exact culture, neutral culture, then default basename; XML is preferred over JSON at each level (for example Translations.en-GB.xml → Translations.en.xml → Translations.xml, then the same sequence for .json).
