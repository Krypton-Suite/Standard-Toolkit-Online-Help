TryAutoDiscover(string?)

Attempts to auto-discover a custom translations file in the supplied directory. If no directory is supplied, uses the application's base directory. Uses the same culture-aware probe order as toolkit translations: exact → neutral → default, preferring XML over JSON, with graceful fallback when a candidate is missing or invalid.

Declaration
public static bool TryAutoDiscover(string? directory = null)
Parameters
string directory

Optional directory to probe.
Returns
bool

true if a file was found and imported successfully; otherwise, false.

TryLoadCultureSpecificFile(string, string, CultureInfo?)

Tries to load a culture-specific custom translations file. Exact-culture, neutral-culture, and default filenames are probed in order, preferring XML over JSON. Missing or invalid candidates are skipped gracefully until a load succeeds or no candidates remain.

TrySwitchCulture(CultureInfo, string?, string)

Switches the current UI culture and reloads the best matching custom translations file for that culture. When no matching file is found, custom string values and registered typed sets are reset to defaults.
