public class PaletteOffice2010LimeGreenDark : PaletteOffice2010Base, IComponent, IDisposable
Remarks

Reuses the Office 2010 Blue chrome (control box glyphs, radio buttons, check boxes, ribbon tab row gradient/rafting) while replacing the button/panel/header/form accent colours with the dark-mode Lime Green accents via LimeGreenSchemeHelper.
