ComposeOverlayImage(Image, Image?, OverlayImagePosition, OverlayImageScaleMode, float, Size, Color, bool)

Composites an optional overlay (badge) image onto a main image. Position and scale behaviour match content overlay rendering in RenderStandard. The caller owns the returned Bitmap and must dispose it.

Declaration
public static Bitmap? ComposeOverlayImage(Image main, Image? overlay, OverlayImagePosition position, OverlayImageScaleMode scaleMode, float scaleFactor, Size fixedSize, Color transparentColor, bool rightToLeft)
Parameters
Image main

The base image. Must not be null.
Image overlay

The overlay image. When null, a clone of main is returned.
OverlayImagePosition position

Corner placement of the overlay relative to main.
OverlayImageScaleMode scaleMode

How the overlay is sized relative to main.
float scaleFactor

Scale factor used by Percentage and ProportionalToMain.
Size fixedSize

Size used when scaleMode is FixedSize.
Color transparentColor

Colour treated as transparent when drawing the overlay; use Empty for none.
bool rightToLeft

When true, Left/Right corners are mirrored for RTL layouts.
Returns
Bitmap

A new bitmap the size of main, or null if composition fails.
