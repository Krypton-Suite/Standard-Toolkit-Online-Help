public bool UseWindowsLanguagePackStrings { get; set; }
Property Value
bool

Remarks

When enabled, general dialog buttons and form control-box tooltips load from user32.dll, and file-system list column headers load from shell32.dll. Custom XML/JSON translations still apply when this is false. Default is false.
