Enum KryptonScreenColorPickerColorFormat

Colour representations that can be shown on the screen colour picker flyout. Combine flags to show more than one format. Use VisibleColorFormats to choose which are visible.

Namespace: System.Dynamic.ExpandoObject
Assembly: Krypton.Toolkit.Utilities.dll
Syntax
[Flags]
public enum KryptonScreenColorPickerColorFormat

Cmyk

CMYK percentages, for example CMYK(8%, 4%, 0%, 2%).

Decimal

Win32 COLORREF decimal value.

Hex

Hexadecimal RGB, for example #E5F1FA.

HexAlpha

Hexadecimal ARGB, for example #FFE5F1FA.

HexInteger

Hexadecimal integer, for example 0xE5F1FA.

Hsl

HSL triplet, for example HSL(204, 60%, 94%).

Hsv

HSV triplet, for example HSV(204, 8%, 98%).

KnownName

Nearest web KnownColor name, for example AliceBlue.

None

No colour formats.

Rgb

RGB triplet, for example RGB(229, 241, 250).

Rgba

RGBA quadruplet, for example RGBA(229, 241, 250, 255).

Vector

Unit RGB vector in 0–1, for example 0.898, 0.945, 0.980.
