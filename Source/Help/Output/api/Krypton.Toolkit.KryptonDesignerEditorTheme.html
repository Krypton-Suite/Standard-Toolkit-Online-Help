Class KryptonDesignerEditorTheme

Resolves and applies designer-editor palettes (saved preference → owner → global), and builds a local theme selector.

public static class KryptonDesignerEditorTheme
Remarks

Theme changes from the selector update only the open editor form. They do not modify the edited component or GlobalPaletteMode. Named themes (and Global) are persisted for the next editor session.
