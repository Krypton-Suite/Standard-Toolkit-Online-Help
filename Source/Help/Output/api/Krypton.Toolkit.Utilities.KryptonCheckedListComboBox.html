Class KryptonCheckedListComboBox

Provides a ComboBox-style control whose drop-down hosts a KryptonCheckedListBox for multi-select with check boxes. Built on KryptonComboBoxUserControl. Implements feature request #3445.

Remarks

The editor shows a summary of checked items (comma-separated by default). The drop-down stays open while the user checks or unchecks items; press Enter (when CloseDropDownOnEnter is true) or click outside to close. List data binding mirrors KryptonCheckedListBox via DataSource, DisplayMember, ValueMember; the editor summary uses display text (respects formatting). Use CheckedItemList for typed value-member results; SelectedValue commits as an array of checked items (see GetCheckedValues()). Documentation: repository Documents/KryptonCheckedListComboBox-DeveloperDocumentation.md (full API and behavior); Documents/KryptonCheckedListComboBox-Guide.md (short overview).
