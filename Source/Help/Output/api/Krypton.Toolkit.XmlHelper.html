ObjectToXmlAttributes(XmlWriter, string, string, object?)

Persist an object as XML attributes when it is a string or has a TypeConverter that round-trips to/from string. Strings write only valueName. Convertible non-strings also write typeName as FullName, AssemblyName. Non-convertible objects are skipped (use custom save events instead).
