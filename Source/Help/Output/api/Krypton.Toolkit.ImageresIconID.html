Enum ImageresIconID

Image resource IDs found in imageres.dll

This enum provides access to the comprehensive collection of system icons stored in Windows' imageres.dll. These icons are used throughout the Windows operating system and provide a consistent visual language for user interfaces. The icons are organized into logical categories for easier navigation and usage.

Usage: Use with GraphicsExtensions.ExtractIconFromImageres() to extract icons at specific sizes. Example: var shieldIcon = GraphicsExtensions.ExtractIconFromImageres(ImageresIconID.Shield, UACShieldIconSize.Medium);
