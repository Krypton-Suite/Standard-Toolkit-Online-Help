Enum KryptonTaskbarProgressState

Specifies the state of the taskbar progress indicator when UseTaskbarProgress is enabled.

Namespace: System.Dynamic.ExpandoObject
Assembly: Krypton.Toolkit.dll
Syntax
public enum KryptonTaskbarProgressState

Error

A red progress indicator shows that an error has occurred. Equivalent to TBPF_ERROR.

Indeterminate

A pulsing green indicator is shown without a specific value. Equivalent to TBPF_INDETERMINATE.

NoProgress

No progress indicator is shown. Equivalent to TBPF_NOPROGRESS.

Normal

A green progress indicator shows the current completion amount. Equivalent to TBPF_NORMAL.

Paused

A yellow progress indicator shows that the operation has been paused. Equivalent to TBPF_PAUSED.
