CenterImage

Gets or sets an optional image drawn in the center of the QR symbol (overwriting modules in that region).

Declaration
public Image? CenterImage { get; set; }
Property Value
Image

Remarks

The control does not take ownership; you must dispose the image when finished. Larger images or higher data density increase scan failures—prefer a higher ErrorCorrectionLevel (e.g. H or Q). Set CenterImageUsePaletteColors to apply palette image effects and color remapping (see CenterImageColorMap, CenterImageColorTo, CenterImageTransparentColor, and CenterImageEffect).

Gets or sets whether the CenterImage is drawn using palette image effect and color-remap rules.

bool

Remarks

When enabled, CenterImageEffect, CenterImageColorMap, CenterImageColorTo, and CenterImageTransparentColor use Empty / Inherit to inherit from CenterImagePaletteStyle on the current palette. Template glyphs that use the Krypton transparency key (Krypton.Interop.SharedStaticVariables.TRANSPARENCY_KEY_COLOR) are remapped to the effective dark module color when the palette does not specify a map color.
