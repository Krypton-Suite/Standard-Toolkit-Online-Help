Class KryptonApplicationUpdater

Checks a JSON manifest or GitHub release, then downloads and applies an installer or a zip. Scheduled checks start only after the component is sited outside the designer. A critical package hides postpone and skip unless its manifest allows them. Resume and Restart can be turned off in the same file. A zip is extracted by the embedded helper so this process is not the one overwriting its own files.

ShowReleaseNotesAsync(CancellationToken)

Reads the feed and shows release notes in their own window. Does not record a check, so the schedule, postpone, and skip state stay as they are. When a newer package exists, that window offers update and remind later. Remind later asks for a date or skips this version. A package that does not allow postpone hides both. When nothing is newer, the window lists the feed and offers Close.
