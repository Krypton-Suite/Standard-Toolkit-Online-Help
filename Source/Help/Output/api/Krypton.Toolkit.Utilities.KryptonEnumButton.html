Class KryptonEnumButton

A button that displays the text of a single enum value and cycles through the values of the assigned EnumType each time it is clicked. Use this instead of a long list of radio buttons when the user only needs to toggle between the members of an enumeration.

Remarks

The button text is derived from the current enum member: the DescriptionAttribute text when present (and UseDescriptionAttribute is true), otherwise the enum field name (optionally humanised via HumanizeNames). The standard Click event still fires on every click, and the dedicated SelectedValueChanging / SelectedValueChanged / EnumValueChanged events report the change.
