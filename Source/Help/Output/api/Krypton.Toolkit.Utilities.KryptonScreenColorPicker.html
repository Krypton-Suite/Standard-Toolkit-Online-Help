Remarks

Inspired by the PowerToys Color Picker overlay (live capture, zoomed pixel grid, hex/RGB readout). Click samples, Esc or right-click cancels. Zoom with the mouse wheel, +/- , Page Up/Down, or arrow keys. Ctrl+wheel, Ctrl+/-, or [ ] changes magnifier size. When an owner window is supplied it is made fully transparent so colours behind the dialog can be picked. The magnifier flyout defaults to themed Krypton chrome; Classic painted PowerToys chrome is still available. Colour formats on the flyout are selected with VisibleColorFormats (hex, RGB, HSL, HSV, CMYK, and others). Drop KryptonColorPicker from the toolbox for a designer-sited component with the same behaviour.
