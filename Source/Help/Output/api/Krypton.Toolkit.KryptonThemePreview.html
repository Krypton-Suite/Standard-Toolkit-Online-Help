Class KryptonThemePreview

Builds a small themed window mock-up for custom-theme previews (issue #3870). Palette Designer and theme-browser export store the result on Thumbnail as base64 PNG in .kthemex.

Resolve(string, KryptonCustomPaletteBase?, bool)

Resolves a preview image for a theme selector row. Stored Thumbnail wins; otherwise a generated mock-up is returned for builtin or custom palettes. Returns null when the caller should use the Stable Kr tile alone (no palette and no stored image).
