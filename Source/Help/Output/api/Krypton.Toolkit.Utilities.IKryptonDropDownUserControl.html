Interface IKryptonDropDownUserControl

Optional contract a developer-supplied UserControl can implement so that the hosting KryptonComboBoxUserControl can drive sizing, life-cycle events and value commit/cancel signalling. Implementing the interface is not required – a control hosted by KryptonComboBoxUserControl that does not implement it will simply be displayed at the size requested via DropDownWidth / DropDownHeight.
