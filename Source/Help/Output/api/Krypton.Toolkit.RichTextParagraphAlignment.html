Enum RichTextParagraphAlignment

Specifies paragraph alignment for a rich text selection, including full justify.

Namespace: System.Dynamic.ExpandoObject
Assembly: Krypton.Toolkit.dll
Syntax
public enum RichTextParagraphAlignment
Remarks

Values match RichEdit PFA_* constants used by EM_SETPARAFORMAT. Use SelectionParagraphAlignment instead of SelectionAlignment when justify is required; WinForms HorizontalAlignment does not include a justify value.

Center

Center text between the margins.

Justify

Fully justify text between the margins (RichEdit advanced typography).

Left

Align text to the left margin.

Right

Align text to the right margin.
