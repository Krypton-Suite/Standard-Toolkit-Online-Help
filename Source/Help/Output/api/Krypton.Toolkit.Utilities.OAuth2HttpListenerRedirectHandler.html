Class OAuth2HttpListenerRedirectHandler

Redirect handler that starts an HttpListener on localhost to receive the OAuth2 callback. Use when redirect_uri is http://localhost:port/callback (or similar).

Remarks

The redirect_uri must be registered with the OAuth2 provider and use the loopback address (e.g. http://localhost:8400/callback or http://127.0.0.1:8400/). The listener starts on the host/port from the redirect URI and waits for the provider's redirect.
