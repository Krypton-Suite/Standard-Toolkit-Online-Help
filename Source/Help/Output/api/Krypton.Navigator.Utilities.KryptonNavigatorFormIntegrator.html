[ToolboxBitmap(typeof(KryptonNavigator))]
public class KryptonNavigatorFormIntegrator : Component, IComponent, IDisposable, IDragTargetProvider
Remarks

Drop this component on a KryptonForm that hosts a KryptonNavigator. Assign Form and Navigator, then set Enabled to activate.

CaptionIntegrated injects a tab strip into the form caption (Ribbon-style InjectViewElement(ViewBase, ViewDockStyle)), switches the navigator to Panel for content only, and keeps the form control box.

ClientChrome hides the form control box and shows form min/max/close button specs on the navigator. CaptionAdjacent keeps the form caption buttons and optionally syncs the selected page text into the form title.
