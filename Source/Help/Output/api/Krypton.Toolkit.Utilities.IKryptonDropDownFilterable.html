Interface IKryptonDropDownFilterable

Optional contract a drop-down content control can implement to participate in the host's "filter-as-you-type" auto-complete pipeline.

Namespace: System.Dynamic.ExpandoObject
Assembly: Krypton.Toolkit.Utilities.dll
Syntax
public interface IKryptonDropDownFilterable
Remarks

When AutoOpenOnType is true and the user types in the editor, the host will automatically open the drop-down (without stealing focus from the editor) and forward the current text to ApplyFilter(string). While the popup is open, Up/Down arrow keys are forwarded to NavigateSelection(int) and Enter is forwarded to CommitSelection(), mimicking the auto-complete UX of a native ComboBox.

Methods
