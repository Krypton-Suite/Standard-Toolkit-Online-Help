PreferNativeGdiText

Gets or sets whether horizontal measure/draw uses P/Invoke GDI (GdiNativeText) instead of GDI+ measure and TextRenderer. Default is false. Rotated orientations always use GDI+. When enabling, measure and draw stay paired on the native path so layout stays consistent.
