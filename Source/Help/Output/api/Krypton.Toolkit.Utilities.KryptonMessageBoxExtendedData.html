ShowDoNotShowAgainOption

Gets or sets a value indicating whether a 'Do not show again' checkbox is shown.

Declaration
public bool ShowDoNotShowAgainOption { readonly get; set; }
Property Value
bool

true to show the checkbox; otherwise, false. Default is false.
Remarks

Caption defaults to DoNotShowAgain unless CheckBoxText is set. The checkbox is shown on the left of the button bar (after the optional Copy button when that is visible). Pair with DoNotShowAgainKey to skip later Show(KryptonMessageBoxExtendedData, bool) calls in this process after the user checks the box. Use Show(KryptonMessageBoxExtendedData, out bool, bool) to read the checked state when you persist suppression yourself.
