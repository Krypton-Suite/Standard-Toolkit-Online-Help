Enum KryptonMessageBoxIcon

Specifies the icon type for KryptonMessageBox.

Namespace: System.Dynamic.ExpandoObject
Assembly: Krypton.Toolkit.dll
Syntax
[TypeConverter(typeof(KryptonMessageBoxIconConverter))]
public enum KryptonMessageBoxIcon

Application

Specify your application icon.

Asterisk

Specify an asterisk icon.

Error

Specify a error icon. The message box contains a symbol consisting of white X in a circle with a red background.

Exclamation

Specify an exclamation icon.

Hand

Specify a hand icon.

Information

Specify an information icon.

None

Specify no icon.

Question

Specify a question icon.

Shield

Specify a UAC shield icon.

Stop

Specify a stop icon.

SystemApplication

Specify the default system application icon. See Application.

SystemAsterisk

Specify the system asterisk icon. The message box contains a symbol consisting of a lowercase letter i in a circle.

SystemError

Specify the system hand icon. The message box contains a symbol consisting of a white X in a circle with a red background.

SystemExclamation

Specify the system exclamation icon.

SystemHand

Specify the system hand icon. The message box contains a symbol consisting of a white X in a circle with a red background.

SystemInformation

Specify the system information icon.

SystemQuestion

Specify the system question icon.

SystemStop

Specify the system hand icon. The message box contains a symbol consisting of a white X in a circle with a red background.

SystemWarning

Specify the system warning icon.

Warning

Specify a warning icon.

WindowsLogo

Specify a Windows logo icon.
