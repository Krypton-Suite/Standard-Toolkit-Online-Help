Class KryptonEnumCommandLinkButton

A command-link styled button (bold heading plus descriptive sub-text) that represents a single value of an enumeration and cycles through the values of the assigned EnumType each time it is clicked. This is the KryptonCommandLinkButton equivalent of KryptonEnumButton (issue #3838).

Remarks

For each enum member the command-link Heading is set to the field name (optionally humanised via HumanizeNames, or supplied by HeadingProvider) and the Description is set to the member's DescriptionAttribute text (or DescriptionProvider). A single enum decorated with DescriptionAttribute therefore populates both lines automatically. Cycling, ordering, and event behaviour are shared with KryptonEnumButton via a common engine.
