EnsureShellAssociations()

Registers per-user Explorer icons for .ktheme and .kthemex.

Declaration
public static void EnsureShellAssociations()
Remarks

Writes HKCU\Software\Classes only (no admin). Safe to call more than once. Failures are ignored so restricted designer hosts still work. Does not replace an existing Open verb that already points at an application executable.

EnsureShellAssociations(string?)

Registers per-user Explorer icons and, when openWithExecutable is a reachable .exe, the Open verb for .ktheme and .kthemex.

Declaration
public static void EnsureShellAssociations(string? openWithExecutable)
Parameters
string openWithExecutable

Full path to the application that should open these files (typically Palette Designer). Explorer uses that executable's first icon (path,0) so a separate .ico is not required. When omitted or not an .exe, only the Stable Kr tile is registered as DefaultIcon.
Remarks

Layout (example for .kthemex): HKCU\Software\Classes.kthemex default = XmlProgId; HKCU\Software\Classes\kthemexfile\DefaultIcon; HKCU\Software\Classes\kthemexfile\shell\open\command = "exe" "%1". The same pattern uses BinaryProgId for .ktheme.

Remarks

Applies ImportWithUpgrade(Stream) so older schema versions are raised to the current persist version before the .kthemex is written. Prefer this over saving a new .xml file. The document inside .kthemex remains XML.
