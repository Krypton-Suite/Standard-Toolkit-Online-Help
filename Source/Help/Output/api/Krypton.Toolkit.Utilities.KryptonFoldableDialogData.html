public class KryptonFoldableDialogData
Remarks

A foldable dialog is a message-box style window with a collapsible ("foldable") details region, modelled on the Visual Studio Just-In-Time debugger dialog. The dialog is rendered by the internal VisualFoldableDialogForm and displayed via Show(KryptonFoldableDialogData).
