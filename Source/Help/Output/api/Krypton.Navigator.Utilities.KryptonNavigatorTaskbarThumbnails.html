Class KryptonNavigatorTaskbarThumbnails

Registers KryptonNavigator pages as individual Windows taskbar thumbnails (IE-style flyout). Drop this component on a form, set Navigator, and leave Enabled true. Clear AllowTaskbarThumbnail on wizard steps that should not appear. Multiple components on the same taskbar-visible host merge into one thumbnail group. Optionally set FormIntegrator and ShowTabGroupThumbnails to insert Explorer-like composite Group | … previews ahead of each catalog tab group's members.
