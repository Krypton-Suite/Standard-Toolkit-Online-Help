Class BugReportGitHubConfigEncryption

Provides AES-256 encryption and decryption for GitHub bug report configuration. Developers use this to create an encrypted config file that ships with their application.

Remarks

The configuration file stores Owner, RepositoryName, and PersonalAccessToken in encrypted form.

Developer workflow:

  1. Create a BugReportGitHubConfig with your repository details and PAT.
  2. Call SaveEncryptedConfig(BugReportGitHubConfig, string, SecureString) with a secret key to create the encrypted file.
  3. Ship the encrypted file with your application (do NOT ship the secret key in source).
  4. At runtime, call LoadEncryptedConfig(string, SecureString) with the same secret key.

Security notes:

  • Uses AES-256-CBC with PKCS7 padding.
  • A new random IV is generated for each save and stored with the ciphertext.
  • The secret key is derived using SHA-256 to ensure a 256-bit key.
  • Store your secret key securely (e.g. environment variable, secure vault) — do NOT hardcode in source.
