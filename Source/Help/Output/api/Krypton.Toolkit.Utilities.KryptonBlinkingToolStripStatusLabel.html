Class KryptonBlinkingToolStripStatusLabel

A ToolStripStatusLabel that can blink using a WinForms Timer. Supports hard colour toggling, soft colour interpolation, and visibility-style hiding. Blink options are grouped under BlinkValues for the PropertyGrid.
