Class KryptonCustomThemeGenerator

Builds a full KryptonCustomPaletteBase from a few seed colours by remapping a builtin donor scheme.

Remarks

The generator copies an Office 2010 or Microsoft 365 donor, hue-shifts chromatic slots toward the seed, overwrites button/header/form accents, snapshots the result into a custom palette, then patches Tracking / Pressed / Checked button colours that would otherwise keep the family's gold/orange LUT. It never mutates GetPaletteForMode(PaletteMode) singletons and never registers type-keyed LUT colours on builtin palette types.
