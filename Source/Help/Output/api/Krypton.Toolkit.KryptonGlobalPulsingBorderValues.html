Remarks

Each group is an independent InputPulsingBorderValues instance. Controls inherit unset properties from the matching group:

  • Forms — KryptonForm
  • Buttons — KryptonButton, KryptonDropButton, KryptonColorButton
  • Inputs — text, combo, numeric, date, and similar input controls
  • Other — KryptonCheckBox, KryptonRadioButton, KryptonLabel
