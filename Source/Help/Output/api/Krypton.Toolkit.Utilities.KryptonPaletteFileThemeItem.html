Class KryptonPaletteFileThemeItem

One selectable theme from a palette file. A .ktheme pack yields one item per named theme. Folder packs use TreePath with / separators.

FromDirectory(string, bool, bool, bool, bool, bool, string?)

Scans a directory for palette files and expands .ktheme packs into named items. Unreadable files are skipped. Nested files and path-named collection themes keep their folder path.
