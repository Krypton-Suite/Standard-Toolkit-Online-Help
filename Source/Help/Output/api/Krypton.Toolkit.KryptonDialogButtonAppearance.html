Remarks

Colours are painted through palette triples (StateCommon, tracking / pressed, and OverrideDefault) so default-button chrome remains intentional. Localized button text remains the accessibility primary; colour is reinforcement only. Help buttons must be styled via Apply(KryptonButton, KryptonDialogButtonRole, KryptonDialogButtonColorOptions?) because they do not assign a DialogResult.
