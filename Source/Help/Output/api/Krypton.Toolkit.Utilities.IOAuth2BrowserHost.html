Interface IOAuth2BrowserHost

Abstraction for the sign-in browser or UI. Implement this interface to use a custom sign-in flow (e.g., system browser, embedded WebView, or custom form).

OAuth2SystemBrowserHost
Namespace: System.Dynamic.ExpandoObject
Assembly: Krypton.Toolkit.Utilities.dll
Syntax
public interface IOAuth2BrowserHost
Remarks

When provided to OAuth2PkceClient, LaunchAsync(string, string, string, IWin32Window?, CancellationToken) is called during AuthorizeWithBrowserAsync(IWin32Window?, string, CancellationToken) instead of the default KryptonWebView2-based form. Use this to open the system browser, a custom dialog, or integrate with platform-specific auth.

The default implementation (when no host is set) uses Krypton.Toolkit.Utilities.VisualOAuth2LoginForm when WebView2 is available.

Methods

LaunchAsync(string, string, string, IWin32Window?, CancellationToken)

Launches the sign-in UI, navigates to the authorization URL, and returns when the user completes or cancels. The implementation must intercept the redirect to redirectUri and extract the authorization code (or error) from the query string.
