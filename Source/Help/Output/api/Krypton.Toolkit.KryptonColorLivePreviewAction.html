Enum KryptonColorLivePreviewAction

Stage of an opt-in colour live preview.

Namespace: Krypton.Toolkit
Assembly: Krypton.Toolkit.dll
Syntax
public enum KryptonColorLivePreviewAction

Cancel

The drop-down closed without a choice. Color is the committed colour.

Commit

The user chose a colour. Color is that choice.

Preview

The user is highlighting a swatch. Color is temporary.

Revert

The pointer left the swatches. Color is the committed colour.
