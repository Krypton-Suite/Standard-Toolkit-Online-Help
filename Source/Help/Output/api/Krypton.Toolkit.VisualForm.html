Remarks

InvalidateNonClient() may run while SuspendPaint() is active, in which case the resulting WM_NCPAINT is ignored. Discrete maximize/restore transitions need the frame painted before DWM presents, so this path temporarily clears the ignore count around RedrawWindow with RDW_UPDATENOW. Interactive drag-resize is not routed here.
