Enum KryptonDialogButtonColorScheme

Named color schemes for optional semantic (accept / cancel / neutral) dialog button colors.

Namespace: System.Dynamic.ExpandoObject
Assembly: Krypton.Toolkit.dll
Syntax
public enum KryptonDialogButtonColorScheme

Custom

Use only the color overrides supplied on KryptonDialogButtonColorOptions.

Deuteranopia

Blue / orange pairing for deuteranopia (red–green) friendliness.

HighContrast

High-contrast fills and borders suitable for HC themes.

None

Do not apply semantic colors; keep themed Standalone chrome.

Protanopia

Blue / brown pairing for protanopia friendliness.

Standard

macOS-inspired green accept and red cancel colors.
