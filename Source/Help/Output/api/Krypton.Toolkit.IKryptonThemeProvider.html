Interface IKryptonThemeProvider

Supplies builtin palette implementations for registration with KryptonThemeCatalog.

Namespace: System.Dynamic.ExpandoObject
Assembly: Krypton.Toolkit.dll
Syntax
public interface IKryptonThemeProvider
Remarks

The core provider lives in Krypton.Toolkit. Additional palettes are supplied by Krypton.Themes via KryptonThemeProviderAttribute and AutoDiscoverThemes. Third-party assemblies can use the same attribute. Extra providers cannot add new PaletteMode values; they can only implement modes that are not already registered. Pass Family and ChromeKind explicitly; the five-argument constructor guesses both from the mode name.
