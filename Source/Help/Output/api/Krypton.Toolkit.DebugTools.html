Remarks

To enable the integrated GitHub issue dialog for NotImplemented(string?, string, int, string?), call ConfigureGitHubReporting(SecureString, string?) at application startup with the secret key for your encrypted config file.

If not configured, clicking "Yes" on the "Not Implemented" prompt will open the GitHub new issue page in the browser.
