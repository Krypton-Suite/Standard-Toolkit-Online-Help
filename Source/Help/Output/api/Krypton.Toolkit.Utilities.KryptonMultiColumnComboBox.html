Class KryptonMultiColumnComboBox

Provides a ComboBox-style control whose drop-down hosts a multi-column KryptonDataGridView. Built on KryptonComboBoxUserControl. Implements feature request #4237.

Remarks

The closed editor shows a single line of text from DisplayMember (or the first visible cell). The drop-down shows a themed grid with optional headers. Data binding mirrors a combo via DataSource, DisplayMember, ValueMember and SelectedValue. Extra ButtonSpecs and palette / rounded-corner styling are inherited from the editor. Documentation: Documents/Development/Krypton-MultiColumnComboBox-Developer-Guide.md.
