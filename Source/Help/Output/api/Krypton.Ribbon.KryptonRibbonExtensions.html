KryptonRibbon targetRibbon

The target ribbon that will receive the merged items.
KryptonRibbon sourceRibbon

The ribbon to merge into this ribbon.
Remarks

This method merges tabs, groups, and contexts from the source ribbon into the target ribbon. If a tab with the same name exists, its groups will be merged. If a group with the same name exists, its items will be merged.

To affect the order of merged items, set the Tag property to a numeric value indicating the desired position.
