Class KryptonTaskDialog

KryptonTaskDialog is a Dialog that resembles the functionality of the Winforms TaskDialog although implemented in a different fashion.
The dialog can be constructed through the individual elements and its properties.

The FreeWheeler1 element exposes only a FlowLayoutPanel (and all it's properties) to which you can add and configure your own set of controls.
Here you can host a choice of controls within KryptonTaskDialog.
